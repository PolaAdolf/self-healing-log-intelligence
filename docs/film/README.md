# Opening animation

Open `index.html` in a browser and choose Play film. This is a canvas illustration, not a video recording or live dashboard. Curves are illustrative, not actual monitoring histories. Browser voices vary by operating system; a prerecorded narration can be loaded instead. Google Fonts are optional and fallback fonts are available offline.

The synthetic demo values come from `../demo_result.json`: 3,692 parsed records, 12 complete windows, anomaly percentile 99.18 versus 98.99, and experimental forecast scores 43.22 and 47.00. Forecast scores are uncalibrated and not incident probabilities. Average precision values 96.33 and 90.70 concern the archive, not this synthetic run. The validation period had zero positive windows.

Business percentages are kickoff targets, not measured results. See `../business_case_targets.md`. No raw customer logs are embedded. The displayed example paths and log lines are illustrative.
