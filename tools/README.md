# Conference deck source

Install `tools/requirements-presentation.txt` into a separate presentation virtual environment, then run `python tools/build_conference_deck.py` from the repository root. It uses the documented screenshot and source values. Re-run the dashboard and update `docs/demo_result.json` before changing any demonstrated values.

PowerPoint is used for final PDF export and slide rendering. Fonts use Georgia and Calibri, the approved fallback pair. Native editable charts, master footers, title placeholders, tables, diagrams and 60–110-word speaker notes are included.
